# Ludo Party 3D V7
Next.js 15 + React + Three.js + React Three Fiber + Drei.

## Install
npm install

## Run
npm run dev

## Build
npm run build

The 3D board is in `components/Ludo3DBoard.tsx`. Existing audio files in `public/sounds` are reused. Replace them with your own SFX using the same filenames when desired.
